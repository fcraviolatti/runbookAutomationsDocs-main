# Highest/Lowest Attribute Value (Commercial)

This Orchestrator plugin picks one node with either the highest or lowest value of a certain attribute.

## Configuration

Attribute  
Node Attribute to sort by.

Sort  
Sort order, `highest` or `lowest`
