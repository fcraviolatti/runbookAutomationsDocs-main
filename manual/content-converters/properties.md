# Properties Converter

Parses Java style [Properties](https://docs.oracle.com/javase/8/docs/api/java/util/Properties.html#load-java.io.Reader-) data into a Java object.

The [HTML Table View Converter](https://docs.rundeck.com/docs/manual/content-converters/html-table-view.html) plugin can render this as a HTML Table.

## Input Types

- `application/x-java-properties` - String

## Output Types

- `application/x-java-map-or-list` - `Map`

## Related Plugins

- [HTML Table View Converter](https://docs.rundeck.com/docs/manual/content-converters/html-table-view.html)
