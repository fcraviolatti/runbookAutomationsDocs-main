# HTML View Converter

Allows HTML embedded in log data to be rendered.

Note: this plugin performs no changes, but passes HTML to be sanitized and rendered.

> **Tips**
>
> See: [Sanitized HTML Output](https://docs.rundeck.com/docs/manual/content-converters/#sanitized-html-output)

## Input Data Types

- `text/html` - `String`

## Output Data Types

- `text/html` - `String`
