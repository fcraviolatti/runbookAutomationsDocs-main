# Loadbalancer Overview

A load balancer allows you to achieve high availability in your Runbook Automation Self-Hosted installation by routing http traffic across several redundant Runbook Automation instances.

This section describes how to configure several common load balancers to achieve a highly available Runbook Automation installation.
