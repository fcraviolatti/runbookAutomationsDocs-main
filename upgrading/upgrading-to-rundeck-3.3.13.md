# Upgrading to Rundeck 3.3.13

3.3.13 included the same Jira Plugin updates that were released with 3.4.0. Be sure to [follow these steps](https://docs.rundeck.com/docs/upgrading/upgrading-to-rundeck-3.4.html#jira-plugins-require-updated-authentication-enterprise) when upgrading if Jira Workflow Steps are in use.
